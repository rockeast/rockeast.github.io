プライバシーポリシー

制定・最終更新　2026年11月6日

本ポリシーは、FASHIONISMの公開サイト、および運営者向けデスクトップツール「FASHIONISM Uploader」における情報の取り扱いを説明します。運営者はFASHIONISMチャンネルの管理者です。

取得する情報と利用目的

FASHIONISM Uploaderは、運営者がGoogle OAuth画面で許可した範囲で、次の情報を扱います。

  • チャンネルID・チャンネル名・動画情報。接続先の確認と二重投稿の防止に利用します。
  • アップロード対象の動画ファイル、タイトル、説明文、タグ、公開設定。YouTubeへの投稿と管理に利用します。
  • 視聴回数、視聴時間、平均視聴時間、登録者数の変化などの分析データ。チャンネル運営の振り返りに利用します。
  • コメント本文、コメントID、投稿者の表示名など、APIが返すコメント情報。コメントの確認と運営管理に利用します。
  • OAuthアクセストークンとリフレッシュトークン。運営者が許可したAPIへの接続を維持するために利用します。

権限の範囲

動画のアップロード、YouTubeアカウント情報の参照、YouTube Analyticsレポートの参照、コメントの管理に必要な権限を要求します。Googleが提供するコメント管理権限には、動画・評価・コメント・字幕の表示、編集、完全削除の権限が含まれます。各操作は、運営者が指示したチャンネル管理の目的に応じて実行します。

保存と保護

認証情報と取得した作業データは、運営者が管理する外付けSSDに保存します。認証ファイルへのアクセスを制限し、ソースコードの公開リポジトリや公開サイトへの掲載を防ぐ設定を行います。取得したデータは、運営目的で必要な期間保存し、不要になった時点で運営者が削除します。

共有とGoogleのユーザーデータポリシー

YouTube APIとの通信ではGoogleにデータを送信します。取得したGoogleユーザーデータを販売したり、汎用AI・機械学習モデルの学習目的で利用したりしません。データの利用・転送には、Limited Useの要件を含むGoogle API Services User Data Policyを適用します。

アクセスの取り消しと削除

運営者はGoogleアカウントのサードパーティとの接続管理から、アプリへのアクセスを取り消せます。あわせて外付けSSD上の認証ファイルと、不要になった取得済みデータを削除してください。権限を取り消しても、すでにYouTubeへ投稿された動画やコメントはYouTube上に残ります。必要に応じてYouTube側で管理してください。

公開サイトと外部サービス

この公開サイトはチャンネル案内と本ポリシーの掲載に使用します。運営者が独自に追加した広告トラッカーやアクセス解析ツールはありません。サイト配信事業者は、配信・セキュリティのためにIPアドレスなどの通常のアクセスログを処理する場合があります。YouTubeなどのリンク先では、それぞれのサービスのポリシーが適用されます。YouTube APIの利用にはYouTubeの利用規約およびGoogleのプライバシーポリシーも適用されます。

お問い合わせ・改定

運営情報・連絡先はFASHIONISMのチャンネルページで案内します。本ポリシーを改定した場合、このページの最終更新日と内容を更新します。
